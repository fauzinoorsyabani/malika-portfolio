## Verified abstract findings

- The project addresses the need for a digital public-service complaint system that not only receives complaints but also provides information about complaint handling.
- The system builds on **LaporinAja**, which had previously been developed through an internship/practical-work context at **Badan Pusat Statistik Kota Tasikmalaya** for the **Program Desa Cinta Statistik** in **Kelurahan Kahuripan**.
- The existing system already provided complaint submission for UMKM actors, but it did **not** allow reporters to track complaint status independently.
- The final project aimed to develop a **web-based complaint information system** with a **complaint-tracking feature** and to test the functionality of the developed system.
- The development method stated in the abstract is **Rapid Application Development (RAD)**.
- The tracking feature uses the **complaint number** as the search identity and adopts the **last four digits of the WhatsApp number** as a simple verification step.
- The system includes **email notifications** to deliver the complaint number and updates related to status changes and follow-up notes.
- **Kelurahan admin** can manage status and follow-up notes.
- **BPS admin** can view complaint details and download complaint recap data.
