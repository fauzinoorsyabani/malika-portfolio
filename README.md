## About the Portfolio

This project is a personal, recruitment-oriented engineering portfolio. Its content presents a system-first approach to digital work: translating requirements into flows, system structure, and implementation decisions. The portfolio uses an **Engineering Field Notes** visual system with a dossier-inspired layout, technical metadata, a natural portrait frame, and an evidence-led roadmap.

The public website is available at [malikaport-khpscvf9.manus.space](https://malikaport-khpscvf9.manus.space). The source repository is private and available at [github.com/fauzinoorsyabani/malika-portfolio](https://github.com/fauzinoorsyabani/malika-portfolio).

## Local Development

### Prerequisites

Install a current Node.js runtime and [pnpm](https://pnpm.io/).

### Run the Project

```bash
git clone https://github.com/fauzinoorsyabani/malika-portfolio.git
cd malika-portfolio
pnpm install
pnpm dev
```

The Vite development server will provide a local URL, normally at `http://localhost:3000`.

### Quality Checks and Production Build

```bash
# Run TypeScript checks
pnpm check

# Create a production build
pnpm build

# Run the built application
pnpm start
```
